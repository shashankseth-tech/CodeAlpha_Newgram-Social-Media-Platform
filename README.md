# Newgram 🌐

**Newgram** is a modern social media platform designed to connect people, share ideas, and build communities through an intuitive and engaging user experience.

## ✨ Features

- 👤 User registration, login, and profile management
- 📝 Create and manage posts
- ❤️ Like and comment on posts
- 🤝 Follow and unfollow users
- 📰 Personalized social feed
- 🔎 User discovery and search
- 🛡️ Admin dashboard with role-based access control
- 🎨 Modern, responsive user interface

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Based on the project's implemented authentication system

## 🚀 Getting Started

1. Clone the repository.
2. Install the project dependencies.
3. Configure environment variables using the provided `.env.example`.
4. Start the backend server.
5. Open the frontend and connect it to the configured API.

Refer to the installation instructions in this repository for the exact setup commands.

## 🎯 Project Goal

Newgram aims to provide a modern social networking experience with a focus on usability, community interaction, and secure administration.
